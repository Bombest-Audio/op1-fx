# Punch factory presets

Twelve presets in `mpc/presets.json`, one file for the MPC VST2 port and the JUCE plugin. Values in the file are each parameter's own units (0..1 floats, `rounds` as a raw integer). This table shows the same values in real units. Generated by `punch_convert.py`.

Units: FREQ is the sidechain high-pass corner (`30 * 2^(8n)` Hz). PUSH is the maximum cascade boost for a strong transient (t = 3) at that ROUNDS count, `N * 20log10(1 + 1.5 * punch / N)`; normal hits get less. POWER is wet mix in percent and also input drive, `20log10(1 + 0.7 * power)`. TOP WINDOW is the fast-attack time of the last active round (`0.3 ms * 1.18^(N-1)`), the slowest transient timescale in play.

## Notes

- Punch has no time or note-value parameters, so nothing here syncs to tempo. Envelope windows are fixed in milliseconds. At 90 BPM a 1/16 is 167 ms and a 1/8 is 333 ms; even 24 rounds only reach a 13.5 ms fast attack, so Punch always acts on the hit itself, not the groove.
- ROUNDS and PUNCH interact: PUNCH is split across the active rounds, so the same PUNCH value gives a different push at 2 rounds than at 24. PUNCH values were solved from the target dB at each preset's own ROUNDS, not scaled by a fixed factor.
- Values in the JSON are rounded to 4 decimals. Init is exactly the OP-1 factory defaults (0.183, 0.458, 19, 0.855).
- POWER adds up to +4.6 dB of input drive before the soft ceiling (linear to 0.75, tanh knee to 1.0). Level match when auditioning; Devvon warns that low-end boosts eat headroom.
- Devvon gave no direct guidance on transient shaping for ad-libs, delay returns, keys or pads. Those rows say so and derive from the DSP. Vocal Lead Lift cites only his parallel-blend advice.
- Not auditioned in a host. Values are derived from the DSP and transcripts, not tuned by ear.
