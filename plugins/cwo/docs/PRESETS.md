# Cwo factory presets

Twelve presets, `mpc/presets.json`, shared by the MPC VST2 port and the JUCE plugin. Values in the file are the 0..1 knob values; the table below shows what they mean in real units. Generated by `cwo_convert.py`, which implements the exact inverse of the core's control curves and checks the result by mapping it forward again (worst error 0.06 percent).

Reading the table: Shift is how far each pass moves the echo, with the direction from SIDEBAND (up is the upper sideband, down the lower, ring is both). Echo is the loop time the ear hears at 90 BPM: the DELAY value plus about 0.29 ms of group delay in the quadrature filter chain. FB is feedback gain. MIX scales the echoes only; the dry signal always stays, so MIX 20 puts the echoes about 14 dB under the input.

## Notes

- Tempo grid at 90 BPM: 1/4 667 ms, dotted 1/8 500 ms, 1/8 333 ms, dotted 1/16 250 ms, 1/8 triplet 222 ms, 1/16 167 ms, 1/16 triplet 111 ms, 1/32 83 ms. The delay line stops at 600 ms, so a quarter note (667 ms) cannot be reached; dotted 1/8 is the longest on-grid value.
- DELAY is quadratic (`1 + 599 n^2` ms), FREQ is exponential (`0.5 (8000^n - 1)` Hz), FDBACK is linear (0.92 n). A linear inverse is wrong for the first two. Cwo has no int parameters, grid cells or shape rows, so none of those conversions apply.
- Devvon gave no direct guidance on ring modulation or frequency shifting in a delay loop. Where a preset cites a transcript, it borrows the principle (micro-shift doubler, modulating the delay return, pitch movement as a feature, frequency shifter as an effect, delay throws, parallel blending), not a setting. Presets marked `none: derived from DSP` have no Devvon source; their numbers come from the core's behavior.
- Preset 0 is the OP-1 factory default exactly (freq 0.1526, delay 0.25, fdback 0.5, sideband 1.0, mix 1.0). The `act` key is never stored.
- Loading a preset glides the delay over about 60 ms, tape style, so the repeats bend briefly on a preset change. Hot input into the FX presets at high MIX will push the output soft clipper; that is intended.
- Not auditioned: these are computed from the DSP and the transcripts, not tuned by ear on the plugin or the MPC.
